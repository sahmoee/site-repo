# Kroger registration URLs

Use these stable public Stocked URLs for provider registration:

- Application: `https://sowensstudios.com/apps/stocked/`
- Logo: `https://sowensstudios.com/assets/stocked-app-icon.png`
- Web redirect: `https://sowensstudios.com/oauth/kroger/callback/`
- Terms: `https://sowensstudios.com/terms/`
- Privacy: `https://sowensstudios.com/privacy/`

Preserve these routes. The static callback intentionally does not render, log, store, or forward query parameters. OAuth token exchange and provider secrets belong server-side in UnifiedWorker.
